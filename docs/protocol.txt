HOST STATUS REQUEST

Hex:    43 4D 53 47 06 49 4E 56 2D 48 42
Python: b"CMSG\x06INV-HB"

Four-byte ASCII header CMSG, one-byte command length 06, six ASCII bytes INV-HB.
Exactly 11 bytes total. There is no appended CR, LF, null terminator or checksum
on this particular request. No parameter-setting requests are implemented.

INVERTER STATUS REPLY

Frame byte(s)   Meaning
0..3            ASCII VPHB (56 50 48 42)
4               Payload length INCLUDING the final checksum byte
5..end-1        Payload data
end             Checksum: sum of payload data bytes modulo 256

Here byte 4 is 0x51 (81), so total length is 5 + 81 = 86 bytes.
For a Python frame: (sum(frame[5:-1]) & 0xFF) == frame[-1].
Header and length are excluded from the checksum.
Use a byte buffer; serial reads may split or combine protocol frames.

The owner confirmed that payload[23] is the AC charger's battery-side DC
output, not AC input amperage. The dashboard labels it AC -> Battery in
A DC. Existing export keys acChargeCurrent and ac_charge_current_a are
retained for compatibility and refer to this same DC measurement.

The owner identified the solar-current field as DC current delivered to the
battery on the tested inverter. Solar current = payload[36] + payload[66] / 10
when field 66 is present. Each charging card multiplies its own current by the
measured battery voltage (fields 20..21) from that same reply to display watts.
Runtime hours = uint16(payload[28:30]) + payload[27] / 10.
Techfine's machine display concatenates field 11 with field 31 * 12: 80 + 48
becomes the displayed string 8048. This field does not independently prove a
manufacturer or a rated real-power output.

Observed status: 08 00 00. The first status byte's bit 3 means charger connected;
bits 0, 1 and 2 mean battery full, controller/AC charging and solar charging.
Warning and fault bytes are all zero in this capture. State step 6 is DC Mode.
The third status byte has controller-warning/fault and charger-warning/fault
flags in its low four bits; all are clear here.

State 4 is labeled "Charging only" based on an owner-confirmed observation on
November 9, 2026: the inverter's AC output was off while solar charged the
battery. AC charging is also available in this mode. The separate charging
flags indicate the active source(s); state 4 alone does not establish nonzero
charging current. This observation is for the tested machine 8048 / firmware
2.10 and has not been independently confirmed for every compatible inverter.

KNOWN INTERPRETATION LIMITS

- The measured output field is around 119.6 V while the configured voltage field
  is 240 V. Both are displayed this way by Techfine. The exact output channel
  represented by the measured field is not established here.
- Battery capacity reports 100%, but the separate battery-full flag is clear.
  Preserve both as reported; do not treat the percentage as verified BMS SOC.
- The controller code is raw decimal 20 (hex 0x14). Techfine prepends "0x" to
  decimal text and displays "0x20". The reader reports the actual raw value and
  correctly formatted hex separately.
- The 13-byte extension is 01 73 82 04 03 01 0A 14 5F 32 6C 00 00 in this capture.
  It is included in checksum validation but its meanings remain unverified.
- Load is reported as a percentage, not watts. No output-power or battery
  discharge-current value is inferred from these decoded fields.
- Validation covers captured responses, ten successful direct status queries,
  and the single bulk-setting change documented below. A battery calibration
  test did not produce the requested readback change; details are below. Other
  setting/calibration writes and the unmapped extension remain untested.
