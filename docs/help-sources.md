# Basic settings help: source record

The in-app Help page is a single plain-English guide. It does not compare manuals or reproduce their tables. It covers the existing serial controls; extra front-panel options in the manuals are not presumed to have known serial write commands.

Source files supplied by the owner:

- `POW-RELAB-SPLIT_SERIES_User_Manual_POW-RELAB-SPLIT_SERIES_User_Manual_V1.7.1105.pdf`: PDF pages 30-37, section 5.6, printed pages 24-31. SHA-256 `89bd2663fd0d1000643ca7d11308586813727ebccf99e47e1c1c5df3f72d6475`.
- `（SKU5）HYBRIDSOLARINVERTER（M）_1761565970979.pdf`: English section, PDF pages 9-11, section 3.7. SHA-256 `860c249d718d54b956048ac609e65e503534a19db4ec2835f040086d10d7a5cc`.

Settings tables were read in full and relevant table pages rendered to check row associations. The guide summarizes purpose, mode choices, percentage-versus-amp units, whole-bank voltage entry and local-versus-device reset behavior. Serial input limits remain the original PC utility's encoded limits; manual front-panel limits were not substituted into unverified serial commands.

Calibration status and app transaction explanations come from the project investigation and implementation, not a claim that either manual documents working CSCA calibration. The complete manuals are not redistributed with this project.
